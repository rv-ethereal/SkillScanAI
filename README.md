## 📌 Overview

**SkillScan AI** is an advanced AI-powered hiring assistant that evaluates candidates beyond resumes.

Instead of just scanning keywords, it:
- Understands job requirements
- Extracts candidate skills
- Identifies skill gaps
- Conducts a dynamic AI interview
- Generates a final hiring decision + learning roadmap

👉 This is not just a chatbot — it is a **multi-step AI agent for intelligent hiring decisions**

---

## 🧠 Problem Statement

Traditional hiring suffers from:
- ❌ Resume keyword bias
- ❌ No real skill validation
- ❌ Time-consuming interviews
- ❌ No structured evaluation system

---

## 💡 Solution

SkillScan AI introduces:

👉 **Autonomous Hiring Workflow**

Job Description → Resume Analysis → Skill Gap Detection
→ AI Interview → Final Evaluation → Learning Roadmap


---

## ⚡ Core Features

### 🧑‍💼 1. HR Portal
- Input Job Description
- Configure hiring requirements
- Calibrate AI interview engine

---

### 👤 2. Candidate Intake
- Upload Resume (PDF / TXT)
- Automatic skill extraction
- Candidate profiling

---

### 🧠 3. AI Interview Agent
- Dynamically generates questions
- Focuses on missing skills
- Multi-turn conversational memory
- Adaptive questioning based on responses

---

### 📊 4. Skill Gap Analysis
- Compares:
  - Required Skills vs Resume Skills
  - Evaluated Skills vs Claimed Skills
- Identifies missing competencies

---

### 🎯 5. Match Score Engine
- Calculates candidate-job fit
- Provides hiring recommendation
- Enables data-driven decisions

---

### 🗺️ 6. AI Learning Roadmap
- Personalized 3-week plan
- Focus on missing skills
- Actionable improvement path
